# Propuestas de interfaz v1 (12 oct 2026)

Copia de respaldo del lienzo de Claude Design "Synced Notes — Propuestas de interfaz"
(artifact en claude.ai, fijado en la barra lateral).

Es solo referencia de diseño: no forma parte de la app ni se compila.
Cada archivo `.dc.html` es una pantalla; `canvas.json` dice cómo están acomodadas.

- `Main.dc.html` — A · Lista compacta (celular)
- `PropuestaB.dc.html` — B · Tarjetas (celular)
- `PropuestaC.dc.html` — C · Colecciones primero (celular)
- `Seleccion.dc.html` — Selección múltiple
- `SelectorColecciones.dc.html` — Selector con búsqueda para muchas colecciones
- `ClaroA.dc.html` — A en tema claro
- `Escritorio.dc.html` — PC: panel lateral + lista + editor

Decisiones tomadas a partir de este lienzo:
- PC: como `Escritorio.dc.html`.
- Celular: Lista (A) y Tarjetas (B) como vistas elegibles; Inicio con colecciones (C) como opción en Ajustes.
- Botón "Nueva nota": como en A.
- Este lienzo no se modifica: los cambios de diseño se hacen sobre una copia.
